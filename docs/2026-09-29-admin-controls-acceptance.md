# 管理员维护入口验收

## 登录页入口修订

按用户后续要求，修改密码入口仅放在登录页右上角、Beta版本标识左侧。实际浏览器核对两者均104×40、纵向对齐，未登录可打开三字段弹窗，登录后移除入口。版本文案为Beta v0.6，版本号来源不变。截图：`docs/2026-09-29-login-password-beta.png`。此轮未再次实际修改密码，未登录改密及安全校验由接口测试覆盖；下文为最初实施验收记录。

## 范围

- 新建任务继续导入项目经理配置；未归档任务卡片可重新导入修改名单。
- 临时取消项目经理只影响主观任务、完成数量和主观汇总。原答案留档，不转交，不继承。客观报告、评审人范围、客观得分和参数保持不变。
- 顶部仅管理员显示「修改密码」，沿用本机共用密码。输入原密码、新密码及再次输入新密码，可切换显示；修改成功后重新登录。
