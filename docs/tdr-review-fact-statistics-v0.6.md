## 范围

本文件仅定义维度一事实统计，不计算客观分、总分、年度贡献排名或等级。主观问卷见《tdr-expert-review-assessment-v0.8.md》；客观30分＋主观70分及阶段4／2／4加权统一在第四模块换算，见《tdr-expert-review-assessment-v0.8.md》。统计仅供授权管理者参考。

本地Excel与飞书归档报告共用解析器。仅统计当前导入的已发生场次；不要求TDR3，不补未来阶段。场次键沿用项目编码＋阶段；同一人多角色只统计一次，代理事实仍归属原评审人。

## 指标

| 指标 | 公式 |
|---|---|
| 出勤率 | 实参场次÷应参场次×100％ |
| 会签率 | 非空且非横杠的会签结果场数÷应参场次×100％ |
| 意见提出率 | 意见总条数÷实参场次×100％，允许超过100％ |
| 含对策意见条数 | 纳入统计的含对策意见数量，用于第四模块每条2分奖励 |
| 代理率 | 代理场次÷应参场次×100％，跨阶段独立展示 |

应参名单来自各场报告。正常、部分参加、改派正常、改派部分计实参；缺席未改派、挂会不计实参。未知出勤保留未知，不推算为正常。会签以项目经理填写的字段为准，不另查提交时间，逾期标记不改变本版“已填写”统计。

意见／问题描述沿用既有摘取、归属、拆分和归一去重规则；同场多条计多条，不再折为一个问题场次。跨不同场次的相同文本分别计数。

## 对策识别与复核

配置及验证通过后，逐条分析本次全部待处理意见，不限制前10条。AI只判断是否有建议、改善措施或技术决策，不评价人员，不补写原文没有的措施。明确的处理方向即可，不强制责任人、期限或参数；通用动词仅作提示，不建立专业词库或关键词评分。

| AI结论 | 默认处理 |
|---|---|
| 包含 | 计入，展示连续原文片段和理由 |
| 不包含 | 不计入，意见总条数保留 |
| 疑似 | 默认计入，标记待确认 |
| 尚未分析或调用失败 | 保持待识别，不伪装成不包含 |

所有已识别结果均可人工纠正。计入／不计入优先于AI结论；页面仅提供计入／不计入两种操作，历史未选择记录仍按AI默认处理。保留原AI结论和修改记录，不改意见总数或归属。一条意见多个动作仍只计一条。

失败保留原因，成功结果逐条写回，重复操作只处理未完成项。详情显示模型及提示版本，未完成时对策数量和奖励保持待统计；未复核疑似项允许试算并标记。疑似统计数指尚未人工选择的疑似意见。

识别质量需要独立人工标注报告验证，检查误纳入、漏识别和人工复核负担。人工点击不自动训练模型或修改提示规则，不能用程序运行成功代替准确率验收。

## 界面与汇总

主表一人一行；TDR1／TDR2／TDR3每组八列：应参场次、实参场次、出勤率、已会签场次、会签率、意见条数、意见提出率、含对策意见条数。最后为独立「总参与评审场次」「代理情况」、详情查看；代理情况显示代理场次／应参场次，跨全部阶段统计。姓名、详情与表头固定，支持表内双向滚动及单阶段／全部阶段汇总切换。项目名称及编码不占主表列。

点击数字显示数量含义或公式、分子分母与计算方法；汇总累计分子分母后重算，不平均百分比。详情称「评审详情」，按项目分段，TDR1／TDR2／TDR3纵向排列，展示阶段参评及会签。区分未导入阶段、未列入名单及没有意见。

副表格的意见详情按TDR阶段和序号组织，意见原文与对策原文片段分开展示，不补写解决方案；疑似标识和计入／不计入按钮随意见呈现。判定理由及修改记录直接展示；来源文件、Sheet和单元格不在详情显示，不再使用「查看证据」折叠。拆分前完整原文保留在载荷和导出，不重复显示。主表数量与副表意见一一可核对，未知或未识别的数量不得冒充确定为0。本次为页面展示调整，统计公式、代理归属及现有导出结构不变。

项目经理提交原始事实、识别结果和人工复核记录；汇总端校验版本、批次、身份、项目归属与重复阶段后重算统计。允许已验证兼容的countermeasure-v0.6及countermeasure-ai-v0.8模型标记随事实载荷导入，各条保留原版本；未知版本拒绝。修改可见Excel单元格不修改系统载荷；载荷哈希用于损坏检测，不作为防篡改签名。

## 飞书人名统一规则（2026-09-14）

TDRX所有结构化姓名字段中，飞书提及形式「@张三」「＠张三」与普通文字「张三」代表同一个人。解析时去掉姓名开头的提及符及相邻空格，再匹配、去重和归属。适用于评审名单、问题提出人、缺席名单、原评审人、代理人及技术项目经理。意见正文及原始证据不做全局替换，姓名内部字符不改动。

## 会签优先规则（2026-09-14）

有效会签优先于缺席名单：同一评审人即使在缺席名单中，只要填写Go、Go with Risk或Redirect，均视为出席并计入已会签场次。导入时提示「已按出席统计」，无需修改报告或额外确认。缺席且无有效会签时仍按既有缺席及代理规则处理。

2026-09-14补充：疑似且未人工选择时，两个选项均不选中，不纳入含对策条数及奖励；人工计入后才纳入，人工不计入则排除。主表提示未确认条数，详情高亮待确认项。主观选项直接展示标题与解释。
