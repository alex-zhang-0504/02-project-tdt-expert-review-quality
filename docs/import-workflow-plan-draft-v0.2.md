# 读取模块交互方案草案 V0.2

状态：用户已确认并补充名称与排版要求，现已实施。本文及同目录 import-workflow-draft-v0.2.svg 保留为原方案草案；最终行为与验收见 2026-09-21-import-policy-acceptance.md，操作以 assessment-workflow-v0.1.md 为准。

1. 当前提醒勾选确有前端门禁作用：qualityGatePassed、canEnterAssessment、compareAssessment 均检查 warningsAcknowledged。方案取消提醒确认动作及对应门禁；提醒只展示、不阻断，错误及未扫描完成仍阻断。
2. 提醒数量后显示「（建议确认并修改报告，但不影响任务进行）」。备注统一黑色、常规字重，姓名始终黑色。
3. 标题改「考核评审人名单」，备注「只考核名单上的评审人」。内部仍取名单与报告人员交集；名单上无报告的人列入未匹配，不虚构数据。
4. 上传控件只留单按钮，初始「上传名单单击此处」，成功后为文件名，再点可替换。长文件名省略并可查看全名；替换读取失败保留此前名单。旁边依次「对比名单」「还原导入名单」。
5. 匹配结果三行：已匹配、未匹配、未纳入；确认状态不再替换匹配分类标签。
6. 中央唯一主按钮状态：读取评分配置 → 正在读取… → 下一步。实际读取成功后显示版本与时间，可展开完整读取凭据。失败保留第一步并显示原因。下一步确认名单及配置快照后进入过程表现，自动重新比对防止使用过期名单。
7. 新增评分配置管理入口，位于AI设置旁。默认只读，输入管理员密码解锁结构化参数编辑。包括阶段权重、基础分、参与度、意见阈值、奖励、主观档位、总分上限与精度。提交前显示变更及影响范围；服务端鉴权、参数校验、冲突检测、原子写入及写后重读。成功才显示永久保存。密码由本机管理员首次设置，只存加盐哈希、不入仓库、不提供默认密码；短时授权，写接口强制校验，不能只隐藏按钮。仅为本地应用管理权限，不代替操作系统文件权限。
8. 配置管理保存持久化到现有JSON，服务重启后继续生效。建议沿用既有快照规则：已进入考核的会话继续使用原配置，新考核读取新配置；读取后、进入前配置发生变化则要求重新读取。若希望已进行的考核直接按新参数重算，需要另确认重算与经理问卷兼容策略。

验收计划：提醒存在可进入、错误阻断；名单上传／替换／还原及匹配；读取失败不变下一步；配置过期重新读取；未授权写入拒绝、参数错误拒绝、并发编辑冲突及写后重启持久化；现有会话快照不漂移。真实浏览器验收宽窄布局、按钮状态和完整操作路径。
