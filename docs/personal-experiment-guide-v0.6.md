# V0.6个人实验设置

日期：2026-09-10。独立可选工具，不属于部门统计规则，不替代固定规则方案，也不表示固定规则引擎已经完成。

## 操作

1. 重启到最新本地服务，点击页面顶部「个人实验设置」。
2. 服务地址固定为DeepSeek官方地址，选择Flash或Pro，自行输入API Key。
3. 点击「开启本次实验」只在本地暂存配置，不调用模型；输入框随即清空，不回显密钥。
4. 点击「测试连接（虚拟文本）」发送一条虚拟建议，校验连接及结构化结果。此操作可能产生API费用。
5. 读取报告并通过质检，打开实验设置，点击「预览本批次前10条意见」；最多10条、共12000字，不自动发送整份报告。
6. 核对预览内容，确认允许外发后勾选并点击「发送预览意见并试验」。文本本身可能包含姓名或技术机密，系统不声称自动脱敏。
7. 查看模型判定、原文片段及理由。结果不写回主表、复核记录或Excel，不影响部门结果。
8. 用完点击「关闭并清除密钥」。关闭弹窗只是隐藏窗口，不等于关闭实验；已发出的请求不能撤回。

## 配置与安全边界

- 默认关闭，不预置密钥，不改.env，不增加全局依赖或系统设置。
- API Key保存在本地后端内存，不在URL、响应、项目文件或导出中出现；会话凭证仅在当前页面内存保存，不使用浏览器持久化存储。
- 配置有效期1小时；过期后不可继续调用。刷新页面需重新配置，旧会话会失效到期，建议刷新前主动清除；服务退出后全部丢失。
- 仅允许本机地址和同源实验请求；页面会话凭证隔离各实验配置。此防护不等于多用户登录权限，不防本机恶意程序或页面被篡改。
- 只向固定官方域名发送意见文本和不含姓名的内部标识；禁用重定向及环境代理，超时45秒，不自动重试计费请求。需代理的网络目前不支持，不能静默改变系统代理。
- 同一会话同时只执行一次调用。未配置、密钥无效、余额不足、限流、网络错误或结构化结果不合格时提示失败，不覆盖原统计。

## 技术依据

按 [DeepSeek官方接入说明](https://api-docs.deepseek.com/) 的Chat Completions协议调用，使用官方列出的deepseek-v4-flash／deepseek-v4-pro。
结构化输出使用 [官方JSON Output说明](https://api-docs.deepseek.com/guides/json_mode/) 的json_object模式，结果再校验意见ID、完整性及原文片段；JSON合法不等于判定正确。
