# 问卷与评分参数配置

- `config/subjective-policy-v0.1.json`：统一说明、六题固定编号及标题、题干、职责边界、卡片标题／解释、无法判断提示、贡献依据提示，以及独立的scores分值部分。单次原子写入保证文案和主观分值同时生效。

- 当前仅本机文件持久保存。登录身份、跨设备同步、跨周期继承不属于本次实现。
- 2026-09-25交互调整：解锁不设倒计时；永久保存成功后服务端撤销本次授权，界面恢复只读。关闭弹窗放弃未保存草稿并锁定。输入框随文案和窗口宽度自动增高，默认展示全文。
