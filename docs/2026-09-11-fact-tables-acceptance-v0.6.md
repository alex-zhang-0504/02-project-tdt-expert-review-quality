# V0.6主副表展示验收

## 本轮范围

主表每阶段九列数量与比率，代理情况为代理场次／应参场次；副表仅项目名、编码、意见详情三列。姓名、代理情况、详情及表头固定，表内滚动。沿用共享design.md的蓝色表头、灰白底色、紧凑边框与字体，不变更主题、计算公式、导出结构或识别服务。

## 已验证

- 135项Python单元测试通过，新增Node渲染断言通过，覆盖九列表头、数量、200％、2/12、未识别数量、三列副表、阶段分组及文本转义。
- 实际浏览器从本地Excel导入虚拟三阶段报告，3位虚拟评审人。汇总甲应参3、实参3、会签3、意见6、提出率200％，未识别对策不伪装为0。
- 单TDR2及全部阶段汇总切换，数字弹窗显示计算公式；代理情况弹窗解释0/3的分子分母。
- 副表按项目一行，仅三列，含三个阶段和六条意见；意见与对策分别展示，来源文件、Sheet、单元格及完整原文可展开。
- 浏览器宽约1280px下，副表宽1240px，内部纵向滚动；主表内部横向滚动，页面无横向溢出，控制台无错误或警告。

## 边界

本轮不实现固定规则引擎或扩展人工复核。疑似按钮保留，渲染由虚拟数据断言覆盖，本轮未用真实模型识别，也未重跑浏览器人工切换与下载链路；后端原有相关回归测试通过。项目名按现有「大TDT-子任务」命名约定取首个连字符后部分；无分隔符保持原名，完整名称保留在证据。没有生成同事验证包。
