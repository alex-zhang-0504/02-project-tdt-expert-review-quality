# 年度服务贡献双指标模拟分析（草稿 V0.1）

> 日期：2026-08-24
> 状态：模拟分析完成，评分规则待确认
> 数据范围：现有14份年度模拟TDRX评审报告

## 1．结论

“评审承担度＋问题贡献度”两个子项分别计2／1／0分具备可行性，但不建议直接使用原始问题总数，也不建议使用问题贡献率。

推荐用于下一轮讨论的口径是：

1. **评审承担度**：按年度实际参与的去重项目数，在当年专家池分布中动态分档。
2. **问题贡献度**：按年度“提出过至少1条有效问题的去重项目数”动态分档；同一项目无论提出几条问题，计分时最多计1个问题贡献项目。

事实卡仍同时展示原始有效问题数、问题贡献项目数和问题清单。原始问题数用于回溯和维度二人工判断，不直接决定服务贡献分。

## 2．模拟范围与数据质量

| 项目 | 结果 |
|---|---:|
| 评审报告 | 14份 |
| TDR场次 | 42场 |
| 虚拟专家 | 21位 |
| 解析错误 | 0项 |
| 解析提醒 | 9项，均为无有效会签提醒 |
| 问题表原始记录 | 38条 |
| 结构完整且可归属到专家的问题 | 38条 |
| 去重后有效问题 | 38条 |
| 有有效问题的专家 | 11位 |
| 无有效问题的专家 | 10位 |

本次“有效问题”只做结构性判断：问题编号、提出人、问题描述和状态完整，提出人可以对应到年度专家。没有判断问题的技术价值、严重程度或最终影响。

同一专家在同一项目中描述实质相同的问题跨阶段重复出现时只保留1条。本批模拟数据未发现此类重复记录，也未发现问题提出人无法匹配专家的情况。

## 4．三种问题指标比较

### 4.1 原始有效问题数

| 有效问题数 | 专家人数 |
|---:|---:|
| 0 | 10 |
| 1 | 3 |
| 2 | 3 |
| 3 | 2 |
| 6 | 1 |
| 8 | 1 |
| 9 | 1 |

参与项目数与原始有效问题数的相关性为：

- Pearson相关系数：0.4731；
- Spearman相关系数：0.3399。

这说明两者存在中等程度的同向关系。参与项目越多，天然拥有更多提出问题的机会；如果直接把项目数和问题总数相加，会部分重复奖励评审工作量，也会产生把同一问题拆成多行的激励。

### 4.2 问题贡献率

```text
问题贡献率＝提出过至少1条有效问题的项目数÷年度参与项目数
```

参与项目数与问题贡献率的相关性接近0：

- Pearson相关系数：-0.1371；
- Spearman相关系数：0.0387。

它与承担量基本独立，但对小样本过于敏感：参与1个项目并提出1条问题时贡献率为100％；参与14个项目并在5个项目提出问题时贡献率只有35.7％。前者可能得到更高问题分，不符合“承担多且贡献多可以累加”的原始目标。

严格按问题贡献率三分档模拟时，服务贡献总分分布为：

| 服务贡献总分 | 专家人数 |
|---:|---:|
| 0 | 4 |
| 1 | 4 |
| 2 | 7 |
| 3 | 6 |
| 4 | 0 |

本批没有任何专家获得4分，说明该方案把“高承担”和“高贡献率”设置成了过强的对立关系。

### 4.3 问题贡献项目数

```text
问题贡献项目数＝年度内提出过至少1条有效问题的去重项目数
```

该指标保留累计贡献，又把同一项目中的多条问题压缩为1个计分单位，可以同时降低项目数量带来的暴露机会偏差和拆分问题刷数风险。

本批11位有问题贡献的专家中，“问题贡献项目数”的上三分位为2个项目。采用以下动态分档模拟：

- 0个问题贡献项目：0分；
- 有问题贡献，但低于当年非零专家的上三分位：1分；
- 不低于当年非零专家的上三分位：2分。

与评审承担度相加后，分布为：

| 服务贡献总分 | 专家人数 |
|---:|---:|
| 0 | 4 |
| 1 | 5 |
| 2 | 3 |
| 3 | 6 |
| 4 | 3 |

该方案覆盖0—4全部档位，既保留“只承担也有苦劳”，也能让“承担多且持续提出问题”的专家获得4分。

## 5．建议的动态计分草案

### 5.1 评审承担度

在年底全部报告导入后，按所有年度参评专家的去重项目数计算上下三分位：

| 条件 | 得分 |
|---|---:|
| 不低于上三分位 | 2 |
| 不低于下三分位且低于上三分位 | 1 |
| 低于下三分位 | 0 |

分界值由当年真实数据生成，不固定为2个、5个或6个项目。同一分界值上的专家必须同分，不按姓名或顺序强制拆档。

### 5.2 问题贡献度

| 条件 | 得分 |
|---|---:|
| 问题贡献项目数＝0 | 0 |
| 大于0，但低于非零专家的上三分位 | 1 |
| 不低于非零专家的上三分位 | 2 |

采用“非零专家上三分位”而不是把正贡献继续切成低档，可以避免专家已经留下有效问题，却仍因年度相对位置得到0分。

### 5.3 合计

```text
年度服务贡献分＝评审承担度＋问题贡献度
```

取值范围为0—4分。是否继续作为年度基础分之外的加分，以及是否允许推动等级跨档，仍待确认。

## 6．事实卡建议展示字段

| 字段 | 是否参与服务分 | 用途 |
|---|:---:|---|
| 年度参与项目数 | 是 | 评审承担度分档 |
| 年度TDR场次数 | 否 | 解释实际参会工作量 |
| 有效问题总数 | 否 | 完整回溯，并支持维度二人工判断 |
| 问题贡献项目数 | 是 | 问题贡献度分档 |
| 问题贡献率 | 否 | 辅助观察，不直接打分 |
| open／closed数量 | 否 | 支持维度二回顾，不处罚问题提出人 |
| 问题编号、项目、阶段、原文位置 | 否 | 审计与人工复核 |

## 7．限制与下一步

1. 本批是随机模拟数据，只能验证算法表现，不能直接确定正式分档口径。
2. 21位虚拟专家的主要角色各不相同，每个角色只有1个样本，无法判断质量、测试、结构、射频等角色是否存在系统性偏差。
3. 当前模板的问题提出人可以对应到专家，但正式数据仍需处理多人共同提出、同义重复和非专家提出的问题。
4. 如果正式采用本方案，应先修改年度《办法》和术语定义，将“问题汇总表不参与任何计分”调整为“问题汇总表不改变维度一意见档位，但可用于年度服务贡献统计”。
5. 正式规则发布前，建议再用一批接近真实年度规模的数据复跑，重点检查三分位并列和不同专业角色的机会差异。
