日期：2026-09-12。视觉规范同步至shared/design/design.md第7.5—7.7节；计分业务不变。

| 模块 | 本轮调整 |
|---|---|
| 读取评审表 | 文件名／当前检查／进度条按45∶22∶33分配，上传区域收紧，进度条填满所在列 |
| 客观数据统计 | 姓名120px、代理与详情各88px；每阶段九列按数量、比率、长标题分配，900px收紧为748px，长表头两行；三阶段表总宽2540px |
| 主观问卷 | 人员列表占18％并限制在180—220px，选项高度62px，前三档等宽，突出贡献两列等宽，小屏单列 |
| 分数统计 | 姓名16％、三个阶段各12％、三个合计各8％、状态14％、依据10％；数字右对齐，总分浅蓝底；阶段明细另按20／11／11／11／11／12／12／12分配 |
| 共享详情 | 项目名／编码／意见18∶12∶70，长内容换行，保留证据折叠 |

统一主面板24px内边距及20px标题下间距，窄屏16px内边距。修正筛选控件纵向排列时flex-basis被当成高度的过大空白。

## 本地验证

- 1440×1000桌面实测进度列约554／271／406px，符合45∶22∶33。客观表九列实测72／72／80／84／80／72／88／100／100px；单阶段视图按容器宽度伸展。
- 详情表实测约227／152／884px，符合18∶12∶70；入口可打开并关闭，问卷保存后仍能在第四模块显示6＋60＝66。
- 分数表实测约215／161／161／161／107／107／107／188／134px，符合设定比例；阶段明细按独立比例展示。
- 390px窄屏逐页检查：四个面板均约351px，页面宽375px，无整页横向溢出；大表在容器内滚动。
- 横向滚动后姓名列位置保持不变，TDR3公式可通过键盘打开。最终构建dc2cfbf5800b5dea补验详情按钮：88px列内按钮约66px宽、31px高，保持单行，点击正常打开副表。
- 11项Web资源及版本测试、主副表Node渲染断言、全部JS语法及git diff --check通过。未新增依赖或修改计分公式。
