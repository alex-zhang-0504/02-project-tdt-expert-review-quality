# 全量AI意见分析与人工确认方案草稿V0.1

状态：2026-09-12根据用户新方向整理，供实施前确认。原通信专有词库已按用户要求删除。本文件仅保留三类通用表达，并定义AI全量分析改造范围；程序尚未改造。

## 一、三类通用表达

| 类别 | 保留内容 |
|---|---|
| 显式标记 | 建议、评审建议、改善建议、改进建议、对策、改善措施、改进措施、处理方案、解决方案、决策、决定、决议、后续动作 |
| 技术选择 | 采用、选用、改用、换用、优先采用、决定采用、确定采用、统一采用、保留、沿用、维持、替换、切换、放弃、取消、暂缓、不采用、暂不采用、不建议采用 |
| 通用动作 | 增加、补充、减少、降低、提高、调整、修改、更换、优化、改善、加强、启用、关闭、禁用、恢复、配置、重设、校准、补偿、隔离、拆分、合并、错开、限制、回退、升级、验证、复测、对比、排查 |

识别重心是动作及动作作用的对象，不再维护通信对象词、通信参数词或领域专有短语库。允许中文／英文冒号、全半角、大小写等常见书写差异。

这些表达只用于定位候选建议／决策片段，并给AI提供提示。所有有效评审意见仍逐条进入AI分析，不因命中动词就跳过AI或直接计算对策数量。

不将「无建议」「未提出对策」误当建议；不将「不建议采用A」一律作为否定排除；「Go」「通过」等纯会签结论不自动作为技术决策。上述区别交由AI结合原文判断，不另建大规模例外词库。

团队推荐在现有评审意见中写：

> 问题：……。建议：增加／调整／更换……。

> 问题：……。决策：采用／保留／不采用……。

不要求增加新表格，不强制写齐责任人、日期、参数值或完整验证条件。

## 二、全量逐条分析流程

1. 用户在已有AI配置入口完成配置及连接检查。在当前有效分析中点击「AI分析全部意见」，展示本次待分析数量并沿用真实意见外发确认。
2. 后台建立任务，按已有opinion_id枚举全部有效意见，每条独立调用AI，不截取前10条，不改变原意见归属、拆分、去重及统计分母。
3. AI判断「是否提出建议、改善措施或技术决策」，输出三类之一、连续原文片段与简短理由。只识别处理方向，不评判专家、不替专家补写建议，不要求证明措施最优或已实施。
4. 每条返回后校验ID、状态及片段是否属于原文，成功即保存并更新统计；一条意见多个动作仍只算一条。
5. 页面显示「总数／完成／待确认／失败」及当前进度。单条超时、限流或格式错误有限重试；持续失败保留失败状态，继续其他条目，允许只重试失败项。
6. 全部条目都有成功结果或明确失败状态后报告任务结束；有失败时不得显示「全部识别成功」。网络失败不等于AI无法判断，也不等于不包含对策。
7. 未完成条目保持待识别，不以0分代替；全部所需数据具备后，第四模块按现行公式重新计算。

正常首次运行覆盖全部有效意见；重复点击防止启动重复任务。对已成功分析的内容，需区分「继续未完成」与「重新分析」，避免无提示重复调用。重新分析保留人工选择及修订记录，不静默覆盖。

当前实现仍是内存服务；新方案不承诺重启后自动续跑。若后续需要持久化任务与断点恢复，应另定存储方案。

## 三、不确定项的用户选择

| AI结论 | 展示与处理 |
|---|---|
| 包含建议／对策／技术决策 | 计入，展示命中原文及理由；允许用户纠正 |
| 不包含 | 不计入，展示理由；允许用户纠正 |
| 无法确定 | 显示「待确认」，提供「计入」「不计入」「暂不判断」 |

「暂不判断」保留待确认状态。默认计数暂沿用当前规范的“疑似默认计入”，页面持续标记含待确认项；如需改为用户确认前不计入，需要单独确认计分口径。

用户选择只改变该条是否纳入，不改意见原文、意见总数或所属评审人。副表三个TDR字段复用同一复核交互；修改后同步刷新事实统计、问卷参考和分数统计。

## 四、现状与改造清单

本轮已读取当前代码确认：个人实验仅发送前10条、最多12000字，不回写统计；正式识别服务尚未连接该实验会话；当前人工计入选择仅开放疑似结果。

| 部分 | 待实施内容 |
|---|---|
| AI入口 | 将配置与正式全量分析连接，统一按钮、状态与外发确认，保留密钥仅内存的边界 |
| 后台任务 | 全量意见队列、单条调用、进度查询、防重复、失败重试和取消后续调用 |
| 返回校验 | 校验每条身份、结果与原文片段，避免漏项、串项及无效结果写入 |
| 结果保存 | 保存AI结论、原因、原文片段及模型／提示版本，保留人工修订 |
| 人工选择 | 所有结果可纠正，疑似提供三种选项，标明AI判定与人工选择 |
| 规范与界面 | 将既有“固定规则为主”的正式方案改为AI全量分析＋通用动词提示＋人工确认，消除旧“只试验前10条”文案 |

## 五、验收标准

- 超过10条的批次可以完整分析，逐条对应原意见，没有漏项或串项。
- 单条失败不吞掉其他条目的成功结果，重试不会重复计数。
- AI返回缺项、错误ID或非原文片段时不作为成功结果保存。
- 疑似、明确包含、明确不包含都能人工纠正，暂不判断保留待确认；再次分析不覆盖人工记录。
- 主表、副表、问卷参考、分数页和导出一致。
- 真实模型连通性与识别效果需要使用已授权的实际配置验证，模拟测试不能替代真实验收。

本轮完成的是词库删除、通用表达整理与方案收敛；全量AI执行链路仍待实施及验证。
