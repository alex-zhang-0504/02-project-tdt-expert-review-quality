# V0.6四维事实统计版

> 当前计分规则：[完整考核办法V0.7](docs/tdr-expert-review-assessment-v0.7.md) 。评审过程表现40分＋专业价值贡献60分＋超额意见奖励，总分100分封顶。全量AI分析仍待实施。

从已归档TDRX评审报告提取评审人的出勤、会签、意见与含对策意见情况，按TDR1／TDR2／TDR3及全部阶段展示。第二模块「评审过程表现」统计事实及评审参与度，第三模块「专业价值贡献」填写问卷，第四模块「分数统计」统一计分，暂不排名、不评等级。

后续识别路线为全量逐条AI分析及人工确认，尚待实施；当前个人实验仍只预览前10条且不回写统计。

## 启动

Windows双击项目中的start.cmd；macOS使用start.command。使用已有虚拟环境和依赖，启动器校验项目身份及构建标识，端口段8865—8899。产品版本v0.6，内部包版本0.6.0，业务规则V0.6。

## 使用

1. 选择集中统计，或项目经理分别提交／统一汇总。
2. 导入本地Excel或飞书归档文件夹，通过格式和身份检查。
3. 查看一人一行的三阶段数量＋比率表；可切换单阶段或全部阶段汇总。代理情况显示代理场次／应参场次。点击数字查看数量含义、公式和说明。
4. 点击详情打开「副表格」，每项目一行，分为项目名、项目编码、TDR1详情、TDR2详情、TDR3详情五列；三个阶段横向并排并自适应均分剩余宽度，大屏自动展开，窄屏表内滚动。意见与对策分开展示，来源单元格等证据默认折叠。
5. 完成AI识别后，疑似项默认计入。详情可切换计入／不计入并保留人工记录。
6. 填写批次后导出Excel；项目经理提交表可用于统一合并，原文、AI结果和复核记录随文件保存。

意见提出率可超过100％；无分母或缺失数据显示“—”。未接入AI时显示待AI识别，不生成虚假的对策率。服务重启后需重新导入；离开前导出Excel保存结果；项目经理提交表可重新合并，集中统计结果目前用于查阅留档，不支持重新载入继续复核。统计资料仅供授权管理者使用，当前本地系统没有登录权限控制。

## 个人实验设置（可选）

页面顶部「个人实验设置」→输入DeepSeek API Key并选择模型→「开启本次实验」→「测试连接（虚拟文本）」。读取报告后可预览前10条意见，核对文本并勾选外发确认后试验。该入口默认关闭，仅本机可用，不要求其他同事配置模型。

密钥仅暂存本地后端内存，有效期1小时，服务退出后失效，不写入文件或导出。刷新页面需重新配置，建议刷新前点击「关闭并清除密钥」。请求直接连接DeepSeek官方域名，不跟随重定向，不使用环境代理。真实文本可能含技术敏感信息，必须确认允许外发；API调用可能收费。

结果只在实验弹窗展示，不修改统计、正式规则或导出；本次未调用真实付费API。详细使用及验收见 [个人实验说明](docs/personal-experiment-guide-v0.6.md) 。

## 六维主观评价

导入并通过检查后，进入「主观问卷」，选择评审人、填写评价人并逐维选档。卡片仅展示小标题，感叹号支持悬停、键盘聚焦或点击查看解释。「查看客观详情」直接打开此人的维度一副表，关闭后继续填写。前五项低档及突出贡献须补充事实依据并关联项目；证据不足可恢复待评价。

点击「保存当前问卷」暂存于本次分析，切换评审人或页面可继续填写；未保存修改会阻止进入分数统计或导出。离开前单独「导出专业价值贡献」留档，刷新或服务重启需重新导入。主观文件不含分值，暂不支持回载或多人合并。规则见 [完整考核办法](docs/tdr-expert-review-assessment-v0.7.md) ，接口见 [主观数据规范](docs/subjective-data-spec-v0.1.md) 。

## 分数统计

进入第四模块，确认本批次已包含应纳入报告后，查看阶段分、有效权重、客观分、主观分及总分；点击「查看明细」追溯分项。阶段内出勤／会签／意见／对策分别为7／7／14／7分，不适用阶段按剩余权重归一，未知或待识别数据不按0分处理。问卷未完成或必填依据未齐时不生成主观合计与总分。可单独导出分数统计Excel留档；当前均为试算，不代表真实规则识别准确率已验收。

## 验证

运行 `.venv/Scripts/python.exe -m unittest discover -s tests`，并在真实浏览器验收导入、数字公式、详情、切换和导出流程。AI准确率需要以新旧报告的人工标注样本单独验收。

评审参与度在过程主表TDR3之后单列展示全部阶段实参场次数；满3场后按本批次前两个不同数量档评5／3分，其余0分，并列同分。各阶段超额意见条数直接相加为奖励，不乘权重；分数导出保留参与度、阶段奖励、封顶前合计及最终总分。
